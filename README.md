## Telegram і розклад

У Django admin додайте кілька записів **Schedule entry** персонально для конкретного учня: оберіть день тижня та час початку для кожного заняття, наприклад четвер 17:00 і субота 11:00. Учні бачать власний щотижневий розклад на сторінці `/schedule/`, а в Telegram доступні кнопки Lessons, Homework і Schedule після прив'язки акаунта через `/start LINK_CODE`.

Щоб надсилати нагадування за 24 і 3 години, запускайте команду кожні 15–30 хвилин у cron або Render Cron Job:

```bash
python manage.py send_24h_reminders
```

Команда безпечна для повторного запуску: журнал доставок не дає повторно надіслати те саме нагадування. Щоб перенести або скасувати тільки конкретну дату, додайте "Schedule exception" всередині відповідного запису розкладу. Нове домашнє завдання автоматично надсилається всім прив'язаним учням курсу та їхнім прив'язаним батькам після збереження в адмінці.
